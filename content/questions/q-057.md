### Prompt
(a) Show that $|\sin z|^2 = \sin^2 x + \sinh^2 y$ and $|\cos z|^2 - |\sin z|^2 = \cos 2x$.
(b) Show that $|\cos z|^2 + |\sin z|^2 \ge 1$. When does equality hold?

### Official Answer / Solution Notes
(b) $|\cos z|^2 + |\sin z|^2 = \cos^2 x + \sinh^2 y + \sin^2 x + \sinh^2 y = 1 + 2\sinh^2 y \ge 1$. Equality holds if and only if $\sinh y = 0 \iff y = 0$ ($z$ is purely real).
