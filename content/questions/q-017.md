### Prompt
If an open set $\Omega$ is simply polygonally connected, is its complement polygonally path-connected? If the complement of a bounded open set $\Omega$ is polygonally path-connected, is the set simply polygonally connected?

### Official Answer / Solution Notes
For bounded open $\Omega$, $\Omega$ is simply connected if and only if its complement $\mathbb{C} \setminus \Omega$ is connected (has no 'holes'). For unbounded open sets, complement path-connectedness can differ depending on whether the point at infinity is included.
