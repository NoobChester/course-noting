### Prompt
Show that if $|z| = R \ne 0$ and $\operatorname{Im}(z) \ge 0$, then $\left| \frac{e^{iz}}{z} \right| \le \frac{1}{R}$.

### Official Answer / Solution Notes
Writing $z = x + iy$, $\operatorname{Im}(z) = y \ge 0$, so $|e^{iz}| = e^{-y} \le e^0 = 1$. Since $|z| = R$, $|e^{iz}/z| = |e^{iz}|/|z| \le 1/R$.
