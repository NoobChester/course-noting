### Prompt
Show that if $f$ and $g = \bar{f}$ are both differentiable in a domain, then $f$ is constant on that domain.

### Official Answer / Solution Notes
Let $f = u + iv$. Then $\bar{f} = u - iv$. For $f$: $u_x = v_y, u_y = -v_x$. For $\bar{f}$: $u_x = -v_y, u_y = v_x$. Equating these yields $u_x = -u_x \implies u_x = 0$, and similarly $u_y = v_x = v_y = 0$. Hence $f$ is constant.
