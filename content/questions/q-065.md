Find all values of (a) $i^i$, and (b) $\sin^{-1} 10$. Which are the principal values?

### Official Answer / Solution Notes
Answer: (a) $i^i = e^{i \log i} = e^{i(i(\pi/2 + 2k\pi))} = e^{-\pi/2 - 2k\pi}$, principal value is $e^{-\pi/2}$. (b) $(2k + 1/2)\pi \pm i\log(10 + 3\sqrt{11})$; principal value is $\frac{1}{2}\pi - i\log(10 + 3\sqrt{11})$.
