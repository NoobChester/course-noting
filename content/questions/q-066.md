Find the principal value of $\left[ \left( \frac{1 + \sqrt{3}i}{2} \right)^{-3} \right]^{1-i}$.

### Official Answer / Solution Notes
Notice $\frac{1+\sqrt{3}i}{2} = e^{i\pi/3}$. So $(e^{i\pi/3})^{-3} = e^{-i\pi} = -1$. The principal value of $(-1)^{1-i}$ is $e^{(1-i)\operatorname{Log}(-1)} = e^{(1-i)(i\pi)} = e^{\pi + i\pi} = -e^\pi$.
