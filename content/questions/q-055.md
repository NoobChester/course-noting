### Prompt
Suppose that $u$ is a harmonic function in an open set $\Omega$, and define the function $g$ on $\Omega$ by $g(z) = u_x(x, y) - i u_y(x, y)$, where $z = x + iy$. Show that $g$ is holomorphic in $\Omega$. If $f \in H(\Omega)$ and $f' = g$, what can you say about $f$ and $u$?

### Official Answer / Solution Notes
Let $U = u_x, V = -u_y$. Then $U_x = u_{xx}$, $V_y = -u_{yy} = u_{xx}$ (since $u$ harmonic), so $U_x = V_y$. Also $U_y = u_{xy} = -(-u_{yx}) = -V_x$. Thus $g$ satisfies CR equations, so $g$ is holomorphic. If $f' = g$, then $\operatorname{Re}(f') = u_x$, so $\operatorname{Re}(f) = u + C$ for some real constant $C$.
