### Prompt
Show that any root $z$ of $z^4 + z + 3 = 0$ satisfies $|z| > 1$ and that any root $z$ of $4z^4 + z + 1 = 0$ satisfies $|z| \le 1$.

### Official Answer / Solution Notes
If $z^4 + z + 3 = 0$, then $3 = |-z^4 - z| \le |z|^4 + |z|$. If $|z| \le 1$, then $|z|^4 + |z| \le 2 < 3$, a contradiction. Thus $|z| > 1$. Similarly, for $4z^4 + z + 1 = 0$, $4|z|^4 = |z + 1| \le |z| + 1$.
