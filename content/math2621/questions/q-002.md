### Prompt
Show that $|e^{i\theta} - 1| = 2 |\sin(\theta/2)|$ for all $\theta \in \mathbb{R}$:
(a) using geometry;
(b) using the algebraic formula $e^{i\theta} - 1 = e^{i\theta/2}(e^{i\theta/2} - e^{-i\theta/2})$.
Deduce that $|e^{i\theta} - 1| \le |\theta|$ for all $\theta \in \mathbb{R}$.

### Official Answer / Solution Notes
For (b): $e^{i\theta/2} - e^{-i\theta/2} = 2i \sin(\theta/2)$, so $|e^{i\theta} - 1| = |e^{i\theta/2}| |2i \sin(\theta/2)| = 2 |\sin(\theta/2)|$. Since $|\sin x| \le |x|$, $2|\sin(\theta/2)| \le 2|\theta/2| = |\theta|$.
