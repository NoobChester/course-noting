Where is the function $f(z) = (z^2 + 4)^{-1} \operatorname{Log}(z + 2i)$ holomorphic?

### Official Answer / Solution Notes
Answer: $f$ is holomorphic on the complement of the set $\{2i\} \cup \{x - 2i : x \le 0\}$.
