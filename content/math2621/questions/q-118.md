### Prompt
Let $n \in \mathbb{Z}^+$. Show that $e^z - 4z^n + 1 = 0$ has $n$ roots inside the unit circle.

### Official Answer / Solution Notes
On $|z| = 1$, let $f(z) = -4z^n$, so $|f(z)| = 4$. Let $g(z) = e^z + 1$. Since $|e^z| \le e^{\operatorname{Re}(z)} \le e^1 \approx 2.718$, $|g(z)| \le e + 1 \approx 3.718 < 4 = |f(z)|$. By Rouché's theorem, $f(z) + g(z)$ has the same number of roots inside $|z| < 1$ as $-4z^n$, which is $n$.
