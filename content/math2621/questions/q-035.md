### Prompt
Suppose that $f(z) = e^z$. Show that the image of a straight line $\ell$ in $\mathbb{C}$ under $f$ is a straight line if and only if $\ell$ is horizontal.

### Official Answer / Solution Notes
If $\ell$ is horizontal, $z = t + iy_0$ ($y_0$ constant), so $f(z) = e^t e^{iy_0}$, which is a ray from the origin (part of a straight line). If $\ell$ is vertical, $z = x_0 + it$, $f(z) = e^{x_0}e^{it}$ is a circle. If $\ell$ is slanted, $f(z)$ traces a logarithmic spiral, which is not a straight line.
