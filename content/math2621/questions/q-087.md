### Prompt
Expand each of the following functions in a Taylor series about the given point $z_0$ and determine the radius of convergence:
(a) $f(z) = e^{-z}, \, z_0 = 1$;
(b) $f(z) = (z + 2)e^{3z}, \, z_0 = 0$;
(c) $f(z) = \frac{1}{z^2 - 5z + 4}, \, z_0 = 2$.

### Official Answer / Solution Notes
(a) $e^{-1} \sum_{n=0}^\infty \frac{(-1)^n}{n!} (z-1)^n$, $R = \infty$.
(b) $\sum_{n=0}^\infty \frac{3^{n-1}(3n+2)}{n!} z^n$, $R = \infty$.
(c) Singularities are at $z = 1, 4$. Nearest singularity to $z_0 = 2$ is $z = 1$, so $R = |2 - 1| = 1$.
