### Prompt
Suppose that $\alpha \ne 0$. Show that $\alpha + 1/\alpha$ is real if and only if $\alpha$ is real or $|\alpha| = 1$.

### Official Answer / Solution Notes
$\alpha + 1/\alpha \in \mathbb{R} \iff \alpha + 1/\alpha = \bar{\alpha} + 1/\bar{\alpha} \iff (\alpha - \bar{\alpha}) - \frac{\alpha - \bar{\alpha}}{|\alpha|^2} = 0 \iff (\alpha - \bar{\alpha})(1 - 1/|\alpha|^2) = 0$. Hence either $\alpha = \bar{\alpha}$ (real) or $|\alpha| = 1$.
