### Prompt
For each of the following functions, state where the function is continuous, and justify your answer:
(a) $f_1(z) = \frac{z^2 + i}{z^2 + 1}$;
(b) $f_2(z) = \frac{z^k}{\bar{z}}$ (where $k$ is a positive integer);
(c) $f_3(z) = (z - i) \operatorname{Log}(z^2 + 1)$.
Is it possible to extend their definition to a larger domain, maintaining continuity?

### Official Answer / Solution Notes
Answer: (a) $z \ne \pm i$; (b) $z \ne 0$; if $k \ge 2$, then $f_2$ can be extended continuously by setting $f_2(0) = 0$; (c) $z \ne iy$ where $y \le -1$ or $y \ge 1$; $f_3$ can be extended continuously across $z=i$ by setting $f_3(i) = 0$.
